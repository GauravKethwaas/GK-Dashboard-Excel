📊 GAURAV KETHWAAS DASHBOARD
Overview
This project showcases an interactive Business Analytics Dashboard built using Power BI.
It provides clear insights into Sales, Orders, Quantity, and Profit, helping track performance across regions and categories.

🔹 Key Features
Clean and professional design with filters for Year, Region, and Category
Visual breakdown of Sales by Category (Art, Computer, Electronics, Mobiles, Storage)
Quarterly trend analysis for Sales & Quantity
Treemap visualization for Quantity distribution
Easy-to-understand KPIs: Total Sales, Orders, Quantity, Profit

📈 Insights
Highest sales observed in Mobiles category
Balanced contribution across Storage, Electronics, and Art
Quarterly performance highlights seasonal variations in demand
Profit margin maintained at 10% across transactions

🛠️ Tools & Technologies
Excel for dashboard creation
Excel/CSV for raw data management
Data Cleaning & Transformation for accurate reporting
